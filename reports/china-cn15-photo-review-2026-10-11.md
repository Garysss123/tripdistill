# China CN15 image source and pixel review — 11 October 2026

## Scope and method

This bounded review covers the 47 distinct local WebP assets displayed on the four CN15 English routes: `/china/`, `/china/beijing/`, `/china/hangzhou/`, and `/china/beijing/summer-palace/`. Each local image was opened and compared visually with its exact linked Wikimedia Commons file page; the depicted place or subject, displayed crop, creator attribution, and declared license/version were checked. The 47 local assets correspond to 46 distinct Commons file pages because the Hangzhou West Lake panorama is used for two different local image files. Four China country-card source checks were already recorded under CN12; CN15 added checks for the other 42 distinct Commons pages.

The target routes' visible credits link each exact Commons file page and license, name the creator and disclose the WebP/resizing or display-crop changes; CC BY-SA adaptations retain their exact source license version. The inventory records what each Commons page declares and the pixel comparison. It does not independently establish uploader authority or a complete rights chain.

Two incorrect credits were corrected after source-to-pixel comparison: the China country-card and Hangzhou hub West Lake credits now point to Haluk Comertel's matching panorama (CC BY 3.0), replacing the mismatched Bjoertvedt source; the China hub's Pudong skyline now credits Ermell's matching file (CC0 1.0), replacing the mismatched King of Hearts attribution. The close Leifeng Pagoda photograph is mapped separately to Tyg728's exact Commons file (CC BY-SA 4.0), not to the West Lake panorama. Potala Palace/Lhasa is excluded and unchanged because its image replacement belongs to separate work. Dunhuang and Sanya child guides were not edited; their existing hub-card images are in scope.

The final column identifies what is visible in the local pixels; it is not used alone as evidence for the source match. Other site images remain outside this review. The current global inventory records 539 used assets without an independent source-page check, so this report is not site-wide rights clearance.
