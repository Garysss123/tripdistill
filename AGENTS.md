# TripDistill project instructions

Read `README.md` completely before changing or expanding this project. Its Editorial release gate and Japan minimum-reference rule are mandatory across models and iterations.

- Compare each new or substantially rewritten page with a Japan page at the same hierarchy level. Record the reference and inspect actual content and desktop/mobile renders; counts alone cannot establish parity.
- Technical audits, translation coverage and successful deployment are not editorial acceptance or evidence of AdSense eligibility. Never call a thin, repetitive template complete on that basis.
- The original U.S. collection is pending staged editorial rework. New York is the first user-acceptance sample; obtain feedback before extending its approach to the other regions.
- The parent workspace `AGENTS.md` remains in force, including image licensing, GitHub backup, Cloudflare Pages deployment and production checks. This file does not weaken or replace those requirements.
